# 原生桌面 release 查询矩阵

同一源码2a6e2db6、CI38179170488的真实平台优化构建，输入20k/200k不可变合成SQLite元数据，每种查询100次。下面均为200k输入；原日志及两种规模全部指标见desktop_matrix.json。该矩阵不测量真实扫描、MCP传输、RSS或冷缓存，不比较不同runner硬件优劣。

| 平台 | 计数前 p50 | 计数后 p50 | 100条目录页 p95 | 100条tree页 p95 | 四读连接最高 p95 |
|---|---:|---:|---:|---:|---:|
| linux-x86-stable | 15.619 ms | 0.019 ms | 0.253 ms | 0.454 ms | 0.679 ms |
| windows-x86-msrv | 10.528 ms | 0.010 ms | 0.136 ms | 0.256 ms | 0.334 ms |
| macos-intel-stable | 61.893 ms | 0.034 ms | 1.099 ms | 2.038 ms | 2.779 ms |
| macos-arm-stable | 9.807 ms | 0.009 ms | 0.119 ms | 0.227 ms | 0.471 ms |

各页面实际节点解码预算按10/100变化；这不是SQLite物理页/字节读取量。四个独立连接的计时不含连接打开。Windows stable作业尚未上传该测量，MSRV结果不能替代它；后续终检窗口改动及服务身份/异常恢复也需各自验收，不据此关闭生产父项。
