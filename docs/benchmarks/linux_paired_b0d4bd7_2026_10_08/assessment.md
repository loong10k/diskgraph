# Linux 同机配对结果

候选 b0d4bd7，基线 2a2f828；同机、相同预创建根，2 轮交替；原生持久身份资格通过，3 个根的名称、内容和身份在四次运行后均未改变。所有回执声明产物的大小及摘要已逐一流式核验。

20k 扫描比基线慢约 2.4%–2.5%；200k 慢约 1.8%–2.4%；300 层深目录慢约 28.8%–31.2%（约 107–110 ms → 141 ms）。这不是扫描加速结果。

200k 候选宿主扫描 RSS 高水位约 207.2 MiB，子进程约 56.0 MiB；两者独立高水位之和约 263.2 MiB，不能称为同时 RSS 或严格上限。基线无子进程，不能仅凭宿主 RSS 差约 11.6–11.8 MiB 掩盖新增子进程成本。

基线沿历史 Engine 入口，候选使用显式进程宿主；适配器、锁文件和测量源码分别绑定。缓存未清空，查询阶段保留夹具证据插入，数据库增量是逻辑文件长度，非物理写入量。结果只覆盖该 Linux 主机的这些夹具，不关闭 Windows、macOS、长期运行或全平台生产门禁。
