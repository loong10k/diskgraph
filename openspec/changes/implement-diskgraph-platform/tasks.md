# DiskGraph 实现任务

本清单属于 [implement-diskgraph-platform](proposal.md)，唯一需求来源为本变更的 14 个能力规格；设计依据为 [design.md](design.md)。这里的“完成”均指实现与验证完成，不指规划文件已经写好。各项状态按下方实现与验证证据维护，未完成的平台门禁不以源码或编译替代。

## 执行约定

- 每项按“规格场景 → 失败测试 → 最小实现 → 回归测试 → 可复查证据”执行；先检查已有实现，不重复重写四个现有 crate。
- 证据记录目标版本、平台、输入夹具、命令、实际结果和限制；不能以 stub、编译、配置生成或 HTTP 200 替代行为验收。
- 所有破坏性测试仅使用隔离临时目录、测试卷或测试容器；不得使用用户真实目录与生产 Docker 对象。
- 阶段可并行研发，但发布必须满足依赖和退出门禁。下面是工作包，不是新建分支、安装软件或执行清理的授权。
- C01–C29 对应 [命令参考](../../../docs/command-reference.md)。引用的 SC/FS/EV 等编号是规格要求，不是代码实现现状。
- 每阶段先复核本阶段任务的实际完成情况及剩余差距；不因后续阶段开始而自动勾选前置任务。
