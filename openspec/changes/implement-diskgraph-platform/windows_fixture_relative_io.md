# Windows 完整负载夹具的原父句柄诊断

事实源沿用本变更。b510f823 Windows 原生包 CI 在 200k 完整流程的原 300 秒总预算到期；创建夹具 231.130 秒后仍在索引，未得到完整结果。本增量仅诊断验收夹具重复完整路径解析的成本，不替换产品实现，不改变文件数量、文件名、32 字节正文、普通文件类型、链接数、宽目录形状、查询覆盖或最终清理要求，不修改权限、主机防护设置、vendored 源码或任何正式时间门禁。

候选通过持有的测试根目录句柄相对创建固定单组件文件名，FILE_CREATE 拒绝既有对象，正常写满 32 字节并关闭原句柄。清理仅按同一固定名称集合相对打开，拒绝重解析、目录、待删除及非单链接对象，通过原句柄标记删除并关闭；完整临时目录退出仍须实际完成。原生失败传播，不以路径缺名、未执行的清理或吞错当作通过。这个夹具工具不是产品的安全文件操作入口，也不提供同权限攻击隔离保证。

先进行原生 A/B/B/A 小夹具诊断，逐项验证名称集合、实际正文与单链接，记录创建和清理实耗及候选源码摘要；小夹具不能外推 200k/300 秒已通过。结果不足或性能变差时不得接入正式验收。当前正式 accept-readonly-load.py 不变，完整 200k 和生产门禁保持开放。

原生契约 7/7 通过。2500 文件 A/B/B/A 完成：创建分别 49.476 / 1.542 / 1.397 / 1.517 秒；两种方法在后续轮次成本接近，首轮异常成本不能归因为稳定优化收益。20k 对照在 240 秒外层诊断上限中断，仅首轮 path 完成（创建 165.778 秒，校验 9.888 秒，清理 11.683 秒）；其间存在 Rust 回放编译重叠，relative 轮次及其清理尚未确认，原始回执仍为 running，外层任务已 timeout。不得把该回执状态视为仍在运行或验收通过，也不得据此改接正式负载。残留诊断根保留待精确回收，不按通配符清理。
