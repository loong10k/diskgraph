# 短竞争输入的原时刻等待

继承已批准的终检250ms数据库窗口、50ms能力回调和原请求期限。生产授权代码不变。a172b51a的macOS stable强制门禁在150ms输入的五次实际释放均超过180ms上界，记录保留；不能用这些结果确认或否定准确短输入的生产行为。

资格夹具短输入改用原持锁Instant的有限CPU等待，两个阶段始终指向原绝对时刻，不因通知、唤醒或上一阶段重计。只在测试执行；500ms持锁和60ms请求拒绝场景继续使用原剩余时间sleep。实际持锁下界与释放上界记录、30ms输入误差、最多五个新隔离输入、五个原场景及原查询结果判定全部保留。抢占仍可能超出输入范围；无法得到合格输入时仍失败，不把固定等待当作原生资格证明。

本机单独的绝对等待单元只证明已消耗准备时间不续期、已过期限返回；完整Engine、原持锁线程、真实SQLite和授权回调场景仍必须在原生CI执行，不以该单元测试替代。与此同时Linux ARM的原镜像门禁在多次debug摘要检查累计30秒处失败，原日志保留；release实际镜像方案待验收，不延长原启动期限。
