# 原包验收失败后保留实际制品

沿用RE-04/06的版本与制品摘要要求。CI `37771002316`五个平台包验收均失败；原上传步骤采用默认成功条件，因此已生成的实际归档、校验和及阶段报告未上传，无法从artifact复验失败对应的完整CLI/MCP制品。

候选让原实际包验收步骤成功或失败后均上传既有`dist/diskgraph-<target>.*`，上传缺失仍报错。不增加continue-on-error、不重试验收、不生成成功报告、不上传用户数据、不公开发布，也不取消正在执行的旧矩阵。构建/准入在包步骤之前失败或取消时不伪造制品。GitHub私有CI artifact本身不代表验收通过；原失败保持失败。真实上传行为仍待下一候选CI验证。

验证：actionlint工作流结构/表达式检查（禁用外部shellcheck）通过，OpenSpec strict通过，diff检查通过。完整actionlint返回56条既有shellcheck诊断；与HEAD原工作流比较、规范化文件路径后完全相同，均非本增量引入，不宣称完整actionlint通过。此为可逆CI条件修改，没有新增镜像行为测试冒充实际上传。
