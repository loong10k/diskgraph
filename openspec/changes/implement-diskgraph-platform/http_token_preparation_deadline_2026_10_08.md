# Token准备共享原持续验收期限

RE-04/06持续夹具原先在签发token之前计算剩余网络等待，准备结束后即使原期限已耗尽仍可发送请求。新增可控时钟场景真实复现第二次token准备耗尽原期限后仍调用网络（断言失败）；候选在签发同主体token后重新扣除原deadline余额，余额耗尽时不启动新网络调用，零次完成仍失败。它不忽略已有请求的超时、不重试、不延长期限、不改产品预算和原60秒/300秒门禁，也不声称macOS原生超时根因已经确认。

目标15项通过；脚本全量320项（319通过、1个本机Windows原生Job测试跳过）。真实持续产品进程与候选同SHA平台包仍待验证；本增量不能关闭持续稳定性或全平台生产父门禁。
