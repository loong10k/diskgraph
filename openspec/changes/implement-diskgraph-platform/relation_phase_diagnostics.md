## 终检细分

随后增加不移动外层时钟的子阶段记录，并验证每次查询准确执行两组连接打开/归属 SQL。
100 次请求产生各 200 个子阶段样本：连接打开 p50 0.205208 ms、p95 0.345792 ms；归属 SQL p50 0.010125 ms、p95 0.021292 ms。
这一轮七阶段合计 p50 1.066750 ms、p95 1.539583 ms，不能与前一轮差值当作性能改进或回退。
子阶段与外层阶段重叠，仅外层七阶段参与 instrumented_phases_total；200 样本混合编码前后两轮。
结果支持优先研究只读连接准备成本，而不是将归属 SQL 或撤权终检缓存；实际优化仍须验证期限、取消、连接隔离及内存预算。
细分测试 1 passed，Engine all-target Clippy 通过。没有据此关闭生产就绪任务。

审查纠正：另用独立起点记录 request_wall，截止策略加载及 review_candidates 返回后，涵盖函数返回和局部资源释放；它与七阶段合计分开输出。测量本身仍含测试插桩开销。

修正后的 release 重跑（1 passed）：request_wall p50 0.988500 ms、p95 1.404167 ms；instrumented_phases_total p50 0.965417 ms、p95 1.374084 ms。
两轮混合子样本各 200 条：terminal_reader_open p50 0.193291 ms、p95 0.316000 ms；terminal_ownership_sql p50 0.009458 ms、p95 0.020125 ms。

## 连接配置假设的反证

新增仅测试、默认 ignored 的 `reader_admission_tests::ownership_reader_configuration_cost_experiment`。
在同一实际迁移 SQLite 库上交替执行完整生产读连接与裸只读连接各 100 次，计时包括实际归属查询和关闭，避免只比较连接准备、将 schema 加载成本推迟到查询却声称优化。
macOS release 完整配置 p50 0.217083 ms、p95 0.315083 ms；裸连接 p50 0.215500 ms、p95 0.344042 ms。测试 1 passed。
裸连接故意没有期限、取消与缓存策略，仅用于反证，不能用于生产。
本轮没有看到删除配置的收益，故不更改生产读连接。后续仍需 Linux 大库证据；缺失归属路径不能代替正向归属性能验收。
