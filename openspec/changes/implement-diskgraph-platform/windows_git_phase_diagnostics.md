原 `DG_PRIVATE_WRITE_PROFILE=1` 只在同线程累计 1024 次写入或一次写入中途失败时输出。已完成的小仓库写入不足 1024 次，无法归因。这轮验收要求：在原 ProbeBudget 生命周期结束时输出同线程观察差值；标明阶段顺序；关闭开关不输出；跨线程转移不相减不同线程的累计量；所有逻辑仅编入 Windows 测试，不改生产预算、原生检查、owner 或清理权。

原生 RED：真实覆写夹具 1/1 行为通过，诊断契约因没有汇总而失败。实现后汇总观察到该夹具实际 8 次写入。一次临时驱动误将次数写为 2，因而失败；按原夹具真实循环 8 次纠正断言，未改夹具或生产实现。持久回归的启用/关闭两项 2/2 通过，均实际启动该原生夹具。

汇总统计是同线程在预算存活期间的写入差值；若存在嵌套预算，各自窗口可重叠，不得将多份汇总相加当作独立请求耗时。`elapsed_us` 包括窗口中的其他工作，`stage_us` 只累计被观测写入阶段，二者不得混同。关闭开关时不采样；测试诊断不是 release 性能验收。

阶段为 preflight、parent_lease、parent_identity、open_create、write、finish_write、observe、finish_operation、return。保持先定位实际瓶颈、再改变实现；当前不勾选任何生产就绪父项。
