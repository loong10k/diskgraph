# 冻结 Linux 基线首因诊断

CI 显式指定的历史 2a2f828（脚本默认 5c9985b 并非本次运行基线） 的 200k wide 基线先后在 10.68 秒、2.96 秒返回 Conflict；事后授权、租约和 owner 有效不证明失败瞬间的原因。当前缺少完整配对结果，性能门禁保持开放。

验收场景：仅在自建历史源码副本中，对冻结 SHA256 匹配的根复核及原生打开实现增加失败分支诊断；记录 openat2 的原始 errno、两次挂载复核的固定失败类型或身份不一致分支。成功路径的原生调用、解析标志、判断顺序、期限、返回值不变，不增加重试或回退。不得将缓存暂不可用的推断写成已确认首因。

适配器必须拒绝源码漂移，候选及其他历史版本不应用该覆盖；回执明确记录覆盖前后摘要并标为 failure-only diagnostic。先运行 Python 红绿合同测试；Linux 原生编译和实际负载证据仍由后续 CI 提供。诊断覆盖不计为产品修复或性能比较通过。

本机验证：新增测试首先因适配函数缺失失败，完成后 5/5；既有 worker/组回收合同 10/10；实际生成的 Rust 覆盖源码经 rustfmt 解析成功。夹具来自 CI 显式指定的 2a2f828 原文件且绑定 SHA256，浅克隆测试无需网络或历史对象。Linux 原生编译和运行尚未完成，不关闭父项。
