# 关系与历史末段能力期限

旧路径在 consumer 之后的授权器延迟 80ms 仍返回允许时，两入口均继续编码。合法发布夹具先确认这两条行为红灯，候选按既有单 revision 的 50ms 能力窗口拒绝迟到允许。控制 SQL 前后阶段独立设期限；回调位于 SQL progress guard 之外。初始 revision 授权仍使用原无内嵌 handler 的 helper，避免嵌套覆盖原执行期限。

独立复核发现提前预算返回会遮盖其他侧撤权及归属隔离；候选改为累计及时性，完成纯 SQL 双侧复检及新鲜归属查询后才拒绝迟到允许。慢回调插入真实隔离记录的两入口回归先确认预算遮盖拒权的红灯，再修正。两入口 × 允许/撤 scope/隔离共六组合通过；另有第一侧慢允许且第二侧已撤权、第二侧慢允许撤第一侧两组合，均精确拒权。所有拒绝均不编码。

旧锁竞争和真实撤权优先回归通过；源码组织门禁 6/0、Engine all-target Clippy 通过。新回归单独放在 terminal_capability_tests.rs，不继续扩大原关系请求测试文件。原生 CI 尚未验收。

限制：多个有限 SQL 观察阶段不等于整个终检总计 50ms。任意同步宿主回调不能被硬抢占，仍不能同 Engine 重入 control mutex。其他初始授权预算审计、Linux stable 历史超时及完整生产验收继续开放。
