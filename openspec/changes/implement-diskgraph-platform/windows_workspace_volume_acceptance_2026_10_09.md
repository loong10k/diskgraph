# Windows正式夹具工作卷

来源：同runner、同提交b355ec80、同三份release镜像、同三个诊断源码摘要的完整200k对比。默认系统TEMP轮总耗时466.412秒，创建158.603、扫描146.176、回收157.550秒；显式工作卷D:\a\_temp轮116.355秒，创建25.184、扫描74.217、回收13.825秒，查询p95 31.985毫秒。两轮均200000文件、200001节点、32查询、4客户端、6/6实际检查，production_acceptance=false。输入绝对路径和根链长度变化（工作卷5个句柄），不是相同路径的代码性能提升，也不证明C盘300秒通过或任意机器SLO。

增量验收：Windows原生打包使用runner提供且实际存在的工作卷作为全部隔离临时目录的父目录。只有Windows覆盖TMP/TEMP/TMPDIR，Linux和macOS环境保留；父目录不可用时拒绝，不回退系统盘。实际包解压、子脚本创建/扫描/查询/回收仍在同一正式入口，所有原参数、每项300秒期限、真实回收、独立构建镜像预期及14项HTTP权限检查保持。不能用独立900秒诊断回执替代新配置的正式成功。

实施范围：只改变CI夹具部署位置，不限制产品支持的盘符、不改变权限或原根名称校验、不删除C盘历史失败、不增加线程或缓存允许结果。新配置须经过真实Windows打包、升级/回滚和200k正式验收后才能关闭对应子门禁；全平台生产及恢复监督/provider父项继续开放。
